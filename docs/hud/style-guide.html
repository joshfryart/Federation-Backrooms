HUD style guide

The on-screen language of Systems Nominal: elbow caps, pills, flat colour blocks on black, bold condensed all-caps labels, segmented bars. An original homage to the control-panel graphics of old sci-fi television; no logos, insignia, names or text are copied. Source of truth: css/hud-skin.css (this page links it). Write-up: docs/hud-review.md.

1 · Colour

Two families that must never be mixed up. Frame colours are decoration: they make shapes pretty and never carry meaning. Meaning colours are the only ones that tell you something, and the same hue always means the same thing in every panel.

2 · Type

Bold condensed all-caps (the stack falls back to Arial Narrow / Roboto Condensed; no webfont is shipped) with wide tracking for labels; mono only for numbers; plain sans for sentences people read (subtitles, comm lines, briefing prose). All sizes are rem, scaled by one variable --z (1 at 1280x720, 1.5 at 1080p).

5 · How to extend

  • New panel: give it class="k-elbow-tl" (or k-cap-l) and set --kc to a frame colour; title in a .k-pill.
  • New state: pick an existing meaning token; add a new one only to :root in css/hud-skin.css and to this page.
  • New meter: .k-seg-bar with --kc and --v. Use rem for sizes so the scale variable works.
  • Never use a frame colour for state, never use a meaning colour for decoration, never put text under 0.75rem on anything the player must read.
  • Motion: pulses and blinks are off under prefers-reduced-motion and body.reduce-motion.
