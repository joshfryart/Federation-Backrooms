LC-12

Button system

One panel-style component set for every button and button-like control in Starfarers: The Backdecks. Styles: css/lcars-buttons.css; behaviours (range fill, segmented select, click blip, Calm class): js/lcars-buttons.js. The game's existing buttons adopt the look by selector; new UI uses the lc-* classes shown here. Flat colour on black, no gradients or glow; black gaps split segments.

Tab through the page to see the focus ring

12-01Pill

.lc-btn: the default. True semicircular ends, one flat colour, the left end cap cut off by a black gap, an optional index number in the top-left corner of the face (data-lc-n). Labels are condensed caps set low and to the right, like a panel key.

12-03Capped

.lc-elbow: rounded left end, flat right end, a black gap, then a squared two-colour bar cap. Used for each screen's main action (Begin shift, Resume, Enter the ship, Begin watch, New run).

12-04Tabs

.lc-tab: a dim face with a full-colour left cap; selected (aria-pressed, aria-selected, .on, .sel) fills with the colour. Comm-log and radio filter chips and the map's deck list use it.

12-05Segmented

.lc-seg: a lilac label cap then segments split by black gaps; the chosen one fills orange (--lc-sel to change). The title's shift-length picker uses it, and the pause menu's Graphics and Crew voices selects are mirrored into one (the <select> stays, visually hidden, with the same id, value and change event).

12-06Settings

Toggles (.lc-toggle: flat pill track, pill knob; off is dim, on is filled), sliders (.lc-range: a bar split every tenth by black gaps that fills to a pill thumb), a destructive reset, and the select fallback (.lc-select) where a select is not mirrored. The rows are the whole hit area.

12-07Keycaps

.lc-key or any <kbd>: a flat tan block with a dark monospace label. The first-run tips (#keyhint) slowly blink theirs gold; Calm visuals holds them still.

12-08Tiles, rows

.lc-tile: action grid buttons (duty board, radio quick actions): icon over label on a dim block with one rounded corner and a colour cap; hover fills orange. .lc-row: full-width rows for talk / terminal menus and the lift panel, with a colour block at the right end; a leading <b> is the number key.
