Button System

One LCARS-style component set for every button and button-like control in Starfarers: The Backdecks. Styles: css/lcars-buttons.css; behaviours (range fill, segmented select, click blip, Calm class): js/lcars-buttons.js. The game's existing buttons adopt the look by selector; new UI uses the lc-* classes shown here.

Tab through the page to see the focus ring

Pill

.lc-btn: the default. Rounded ends, a darker two-tone end cap split from the face by a black gap, an optional index number on the cap (data-lc-n), top highlight + inner shade + soft outer glow in the face colour. Labels are condensed caps, right-aligned like a panel key.

Capped / elbow

.lc-elbow: rounded left end, flat right end, then a separate squared two-colour bar cap. Used for each screen's main action (Begin shift, Resume, Enter the ship, Begin watch, New run).

Tabs and chips

.lc-tab: dark face with a coloured left cap bar; selected (aria-pressed, aria-selected, .on, .sel) fills with the colour. Comm-log and radio filter chips and the map's deck list use it.

Segmented selector

.lc-seg: a lilac label cap then joined segments; the chosen one fills orange (--lc-sel to change). The title's shift-length picker uses it, and the pause menu's Graphics and Crew voices selects are mirrored into one (the <select> stays, visually hidden, with the same id, value and change event).

Pause-menu settings

Toggles (.lc-toggle: pill switch, inset knob, ON / OFF marker), sliders (.lc-range: segmented track that fills to a pill thumb), a destructive reset, and the select fallback (.lc-select) where a select is not mirrored. The rows are the whole hit area.

Keycaps

.lc-key or any <kbd>: light key face, darker bottom lip, monospace. The first-run tips (#keyhint) make them glow gold; Calm visuals holds the glow still.

Tiles and list rows

.lc-tile: action grid buttons (duty board, radio quick actions): icon over label, coloured cap bar, fill orange on hover. .lc-row: full-width rows for talk / terminal menus and the lift panel; a leading <b> is the number key.
